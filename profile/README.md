## What Is NexusFont

NexusFont is a light preview helper for choosing type without a long detour. NexusFont font preview is the main window. NexusFont font group is the shortlist. People making a class handout, a club poster, or a birthday card can compare a few faces and move on. The collection can be large. The decision should stay small.

NexusFont quick compare is for the last two or three names. NexusFont type sample shows the exact words of the title. NexusFont font set saves that little bundle so next week’s edit starts in the same place. You are organizing a choice, not building a type studio. Faces you are not allowed to use should stay out of the group.

A good session is short. Type the real line, scan NexusFont font preview, drag keepers into NexusFont font group, and finish with NexusFont quick compare. Save the result as a NexusFont font set. NexusFont type sample is the check that the title still reads across the room.
